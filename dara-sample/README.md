# dara-sample · AutoMuse

An interactive, static demo for the JEVathon: a Tesla finder that shows a clearly synthetic buyer profile, five ranked vehicle choices, condition evidence, and controls for re-ranking the matches.

Open `index.html` in a browser, or serve this directory with any static HTTP server. The data is intentionally fictional. The live version would replace `listings` in `app.js` with MarketCheck inventory, then use JEV to classify inspection and records evidence before calculating a final score.
